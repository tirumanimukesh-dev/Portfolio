## 📋 Overview

A **modern, high-performance Full Stack developer portfolio** built with React, TypeScript, and Tailwind CSS. Featuring interactive animations, responsive design, glassmorphism UI, and a sleek developer-focused interface to showcase my skills, projects, certifications, achievements, and experience in full-stack web development and software engineering.

## 🚀 Getting Started

### Prerequisites
- Node.js 20.x
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/tirumanimukesh-dev/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The dev server will start at `http://localhost:8080/`

### Build for Production

```bash
npm run build
npm run preview
```
